HEAD TREATMENT
26,000 points held in a volume, not on a shell — the head reads as a field that happens to be dense in the shape of a face. 12% of the points are amber: the signal inside the noise. It never renders a surface, so it can never look like a failed render.
MOBILE
3,000 points on a 2D canvas, no depth sort, no additive blending — the silhouette and the waveform survive, the glow doesn't. Under 380px or reduced-motion: one still frame plus the amber caret.

WORK The head scatters into a waveform band and the projects scroll through it. The band is the section divider — no rules, no cards.
ABOUT Points re-condense into profile. Reforming from noise is the argument the About copy makes in words — it doesn't need to be said twice.
CONTACT Decay upward into a sparse field. Contact sits in the thinned-out space it leaves behind, amber on void.
Closest to the reference in mood, furthest in logic: the motion is voice, not spectacle. Two accents, so it never reads as neon-on-black.

HEAD TREATMENT
Matte plaster, flat-shaded so every facet is visible — the stylisation is a manufacturing method, not a filter. One hard key light and a real cast shadow on the floor. It sits on a plinth because a museum cast always does.
MOBILE
No renderer at all: five pre-rendered light-sweep frames, cross-faded on scroll, ~180 KB total. Fixed lighting means fixed frames are honest — the desktop and mobile builds show the same object.
SCROLL JOURNEY — CLICK TO DRIVE
HERO Three-quarter view, key light hard from the left, shadow thrown right across the floor. Nothing moves but a 0.12 rad drift.
WORK The light sweeps left to right as you pass the four projects — each one owns a lighting angle, so the same object is a different object per case study.
ABOUT Full profile, key light dropped low. The shadow lengthens across the whole section and the About text sets inside it.
CONTACT The key light cuts. Only ambient remains — the cast goes flat and grey, and the contact lines are the brightest thing on screen.
The furthest from the reference: lit room instead of void, physical object instead of digital effect, light doing the work instead of geometry.
