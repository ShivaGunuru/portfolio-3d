bake hero video

Dev-only tool. Rebuilds src/assets/hero-field.bin and hero-field.json from a new set of extracted video frames. Only run via npm run dev, never in the production build.

1. Extract frames with ffmpeg (already on PATH for this project). From the project root:

mkdir -p public/_bake-frames
ffmpeg -i "path/to/source.mp4" -vf fps=<FPS> public/_bake-frames/frame%03d.png

Pick an FPS that lands you 40-60 frames across the clip's length; more doesn't meaningfully improve smoothness since the runtime already interpolates between baked frames, it just makes the bake slower.

2. Set the frame count below to match what ffmpeg produced, then run the bake.

3. Move both downloaded files into src/assets/, overwriting the existing pair. Delete public/_bake-frames/ before committing; it's scratch input, not a shipped asset. Then re-run npm run build and check the result before pushing — a bad bake is a rendering regression, not a typecheck error, so nothing here catches it for you.
