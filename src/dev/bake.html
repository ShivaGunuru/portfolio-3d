bake hero cutout

Dev-only tool. Rebuilds src/assets/hero-cutout.png and hero-cutout.json from a new set of extracted video frames: the subject with its background removed, packed into a sprite sheet the Hero section steps through as the page scrolls. No particles, no shader effects — this is real video pixels. Only run via npm run dev, never in the production build.

1. Extract frames with ffmpeg (already on PATH for this project). From the project root:

mkdir -p public/_bake-frames
ffmpeg -i "path/to/source.mp4" -vf fps=<FPS> public/_bake-frames/frame%03d.png

Pick an FPS that lands you 30-45 frames across the clip's length. Unlike a particle bake, this one steps directly to the nearest frame rather than blending, so closer-spaced frames make the scroll motion look smoother; going much above 45 mostly just grows the sprite sheet.

2. Set the frame count below to match what ffmpeg produced, then run the bake.

3. Move both downloaded files into src/assets/, overwriting the existing pair. Delete public/_bake-frames/ before committing; it's scratch input, not a shipped asset. Then re-run npm run build and check the result before pushing — a bad bake is a rendering regression, not a typecheck error, so nothing here catches it for you.
